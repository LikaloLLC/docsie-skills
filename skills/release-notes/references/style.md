# Release notes style

- Write for customers, not for the team that built it. Say what changed for them.
- One bullet per change, one or two sentences.
- Start with what the reader can now do or what no longer goes wrong:
  - New: "You can now export a book as a PDF."
  - Improved: "Search results now show the matching section."
  - Fixed: "Pasting from Word keeps numbered lists."
- Present tense. No "we", no exclamation marks.
- Name screens, buttons and settings exactly as they appear, in bold: **Export**, **Settings**.
- No ticket numbers, branch names or people's names.
